# Day 01 - Quiz answers

1. `System.out.println("2 + 3");` shows `2 + 3` (text, in quotes). `System.out.println(2 + 3);` shows `5` (Java calculates).
2. A compile error (`package system does not exist`): Java is case-sensitive; the class is `System`, not `system`.
3. The closing quote is missing: `System.out.println("Hello");`.
4. `print` stays on the same line; `println` finishes the line (moves to a new one).
5. Two lines: `a` and then `b` on the next line (`\n` = new line).
6. It starts a comment; Java ignores the rest of that line.
7. False - top to bottom, line by line (inside `main`).
8. The **first** one; later errors are often side effects of it.

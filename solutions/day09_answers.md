# Day 09 — Quiz answers

1. `{}` is a **dict**. Empty set: `set()`.
2. `{2, 3}`.
3. Sets are unordered, so there is no position/index.
4. `TypeError` — tuples are immutable.
5. `a, b = b, a`.
6. `3`.
7. A **set** (hash lookup, roughly constant time); a list is scanned item by item.
8. `(5)` is just the number 5 in brackets; `(5,)` is a one-item tuple.

# Day 08 — Quiz answers

1. `[1, 2, 3, 4]` — `b = a` makes both names point to the same list.
2. `None` — `sort()` changes the list in place and returns nothing.
3. `append(x)` adds one item (even if it is a list); `extend(iterable)` adds each element.
4. `[20, 30]`.
5. `pop()` removes by position (default last) **and returns** the item; `remove(x)` removes the first item equal to `x`; `del lst[i]` removes by index without returning.
6. Nothing — it returns a new sorted list.
7. `[0, 0, 0]`.
8. `first = 1`, `rest = [2, 3]`.

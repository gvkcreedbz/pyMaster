# Day 01 — Quiz answers

1. `print("2 + 3")` shows `2 + 3` (text, in quotes). `print(2 + 3)` shows `5` (Python calculates).
2. `NameError` — Python is case-sensitive; the function is `print`, not `Print`.
3. The closing quote is missing: `print("Hello")`.
4. `A-B`
5. Two lines: `a` and then `b` on the next line (`\n` = new line).
6. It starts a comment; Python ignores everything after it on that line.
7. False — top to bottom, line by line.
8. The **last** line (error type and message), then the line number above it.
